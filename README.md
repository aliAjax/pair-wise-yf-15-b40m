# hxyfront-62003 法医昆虫学样本记录

源提示词编号：5

法医昆虫学样本台账前端工具：按案件登记采样地点、原始温度、暴露阶段、虫种、发育阶段、采样时刻和保存方式；补录校准依据、适用时段和偏差值后自动生成修正曲线与阶段测算。校准信息或关键温度点缺失时样本停在「待复核」，旧结论仍有效；补齐后重算并保留每次修正。

## 功能

- **批次台账**：样本列表 + 发育阶段筛选（卵/幼虫/蛹/成虫）+ 案件筛选 + 状态徽标
- **案件关联**：按案件归组查看样本、当前有效结论与待复核数量
- **样本详情卡**：台账字段、温度记录图（原始曲线 vs 修正曲线，未覆盖点红色标记）、校准补录、温度点补录、修正历史时间线
- **登记样本**：台账字段 + 原始温度点批量录入，登记即首次测算

## 核心规则

- 原始温度曲线登记后**只增不改**，补录温度点不会覆盖历史读数
- 校准（依据 / 适用时段 / 偏差值）独立补录，修正温度 = 原始温度 + 偏差值
- 每次补录触发重算，生成一条修正快照（修正曲线 + 有效积温 ADH + 阶段测算），**历史结论全部保留**
- 缺校准、温度点不足或部分时段无校准覆盖时，样本停在「待复核」，最近一次结论仍然有效

## 目录结构（规则 / 存取 / 界面分离）

```
src/
  domain/    规则层：类型、校准修正、积温测算、待复核判定（纯函数）
    types.ts   实体：样本 / 温度点 / 校准 / 修正快照
    rules.ts   修正曲线、ADH、阶段测算、状态判定
    vocab.ts   领域词表（暴露阶段、虫种、保存方式等）
  data/      存取层：localStorage 持久化 + 种子数据
    storage.ts seed.ts
  ui/        界面层：批次列表、案件关联、详情卡、温度图、登记表单
```
